# 功能缺口盤點：對照台灣市售中小企業 ERP／會計軟體（2026-07）

> 方法：取四家主流產品的公開功能清單與產品手冊逐項對照——文中 MERP、正航一號、鼎新 A1 商務應用雲、叡揚 Vital Finance（另參考華崗）。
> 結論驅動 ROADMAP 的批次排序；本檔為快照，完成一項就在勾選框打勾。

## 我們已有（且比同級入門版深的部分）

進銷貨單＋自動拋轉傳票、移動平均成本、庫存查詢、試算表；電子發票開立/作廢/重開/沖銷（MIG-4.1 XML 自產）、進項發票登錄、401 媒體檔＋申報書檔；記帳士匯出 CSV。市售產品的 401 申報多為加購模組，我們的「交易→發票→申報」縱深是差異化優勢。

## 第一層：帳務完整性（記帳士門檻，市售標配）

- [x] 手工傳票（調整分錄、費用、期初科目餘額）— 2026-07-22 本批次
- [x] 收款單／付款單（沖應收/應付＋未收未付餘額）— 2026-07-22 本批次
- [x] 期初開帳：庫存開帳（量＋成本）＋科目餘額（走手工傳票）— 2026-07-22 本批次
- [x] 資產負債表、綜合損益表 — 2026-07-22 本批次
- [x] 現金流量表（直接法：現金分錄按對方科目分類三大活動）— 2026-07-27
- [~] 銷貨退回/進貨退出＋折讓 — **帳務面已做（2026-07-29）**、憑證與申報面未做
  - 已做：退回／折讓單（來源單據上開單、明細必須指向原單明細）、自動拋轉傳票（收入減項走 4109、
    對方科目自動拆分 1144／2201／現金）、庫存回補與成本按原單成本比例攤＋軋平、
    進貨退出的在庫金額上限與差額回沖 5101、退貨當期認列（`assertPeriodOpen` 看退貨日）、
    累計退回量服務層把關、應收帳齡／未沖餘額／對象餘額／儀表板四處取數同步扣減。
    同批補上 `cancelInvoice` 缺少的關帳鎖，並擋下「已有退回單的銷貨單再走整單沖銷」。
  - **未做（等 Turnkey 憑證的只有最後兩項）**：
    401 申報書的退回折讓減項欄位（現仍硬寫 0 → **會多繳／少繳稅，每期須人工補填**）、
    媒體檔的證明單明細記錄（要用哪些格式代號未查證，見 vat-401-403.md 待確認表）、
    G0401/G0501 折讓證明單 XML、對外傳輸。
    落差明細與人工替代步驟見 `docs/specs/vat-401-403.md`「退回折讓的已知落差」。
    註：401 減項與 G 系列 XML **不需要憑證就能做**（repo 內已有四份官方 G0401/G0501 範例可做 golden 測試），
    真正卡在憑證的是傳輸與驗測；原本把整包壓在 Phase 2b「等 Turnkey 憑證」是排序上的誤判。
